# Instalação do Squid com CMEasy

Esta pasta contém o guia de instalação e ativação do serviço Squid através da ferramenta CMEasy.

## Guia disponível

O [guia de instalação](proxy-squid-cmeasy.md) apresenta:

1. Referências para obter e instalar o CMEasy, incluindo um tutorial em vídeo.
2. O percurso no menu: **Linux → Distribuição → Programas → Proxy Squid**.
3. A instalação do Squid através do módulo correspondente.
4. A ativação do serviço e a confirmação do seu estado.

O procedimento pressupõe permissões administrativas no sistema. Esta pasta contém a documentação do processo; o instalador do CMEasy é obtido através das referências indicadas no guia.
